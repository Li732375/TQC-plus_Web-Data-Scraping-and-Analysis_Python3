## 作答提要
 - 基本上，答案都在提示提及了。
 - 其餘按程式撰寫邏輯就能順利完成了。
 - 套件 pandas 讀入 csv 檔的方法名稱為 read_csv。
 - 判斷資料型態用方法名稱為 type，為預建方法。
 - 套件 numpy 下名稱：
   1. 平均值方法名稱為 mean
   2. 中位數為 medain
   3. 標準差為 std
   4. 變異數為 var
   5. 極差值為 ptp
   
## 特別注意
 - 資料型態不符？採用類別方法 to_numpy 試試！
    - 另一種做法，用套件 numpy 下方法 array 也行，輸入要轉換的變數做參數。
 > **跳出 FutureWarning？**採用類別方法 to_numpy 即可。但並非所有方法都有此要求。
